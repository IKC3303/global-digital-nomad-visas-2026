## 📊 Dataset Highlights
- **Coverage**: 35+ Sovereign Nations (Europe, Asia, Americas, Middle East, Africa)
- **Currency Parity**: Statutory local currencies (€, $, ฿, ₩, ¥, AED) + normalized USD floors
- **2026 Tax Frameworks**: 5 Tax Archetypes (Pure 0% Tax, 1% Business Concession, Remittance-Bound, Special Expat Flat, Standard Global)
- **Formats**: Available in `JSON` and `CSV` (RFC-4180 compliant)

## 📥 Direct Downloads & API Access
- **JSON Format**: [`dataset.json`](./dataset.json) or `https://oneisolve.com/dataset.json`
- **CSV Format**: [`dataset.csv`](./dataset.csv) or `https://oneisolve.com/dataset.csv`
- **Machine-to-Machine API**: `https://oneisolve.com/developers`
